# Swiper

A fast, mobile-friendly spike-dodging arcade game. Swipe up and down to switch lanes, beat your best score, challenge the bot, and create or play community-made levels.

### Features

- Practice, bot, and quick-play modes
- First-time gameplay tutorial with replay in Settings
- Community level editor with top/bottom spike patterns and difficulty settings
- Community level browser with creator names and level titles
- Supabase-backed accounts, scores, and published community levels
- Animated, low-contrast Swiper background and responsive controls

## Play

Open the project's GitHub Pages website to play in your browser. Create an account to publish community levels.

Community level names are checked for inappropriate language.
